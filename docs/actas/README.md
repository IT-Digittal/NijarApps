## Cómo usarlas

1. Copia la plantilla, renómbrala con la fecha: p. ej. `2026-04-15_acta-kickoff.md`.
2. Rellena los campos entre corchetes `[...]` y marca las casillas `[ ]` → `[x]`.
3. Fírmala (Director de Proyecto IT DIGITTAL + responsable municipal).
4. Archívala en el repositorio de evidencias, ordenada cronológicamente.

## Convenciones comunes a todas las actas

- Toda acta debe citar el **expediente 18962/2025** y la referencia PRTR:
  «Plan de Recuperación, Transformación y Resiliencia – Financiado por la Unión
  Europea – NextGenerationEU», Mecanismo de Recuperación y Resiliencia
  (Reglamento (UE) 2021/241), Componente 14.
- Las decisiones se registran con **responsable** y **plazo**.
- Las actas se entregan en formato abierto y firmadas por el Director de Proyecto.
